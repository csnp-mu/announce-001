# announce

スケジュールに基づいた音声アナウンスアプリです。

## 機能

- 📅 スケジュール管理（CSV 読み込み対応）
- 🔊 音声再生（標準音声 + カスタム音声設定）
- 📱 iPhone/iPad 対応
- 🎵 音声ファイルのカスタマイズ（個別/フォルダ一括設定）

## 使用方法

### デモモード

1. 🗓️ 1/2/3/4/5/6 ボタンでデモスケジュールを選択する
2. ▶️ 再生ボタンでスタートする
3. 設定した時間になると音声が自動再生される

### カスタム CSV の読み込み

1. 📁 CSV 選択ボタンで CSV ファイルを選択する
2. ファイルアプリ（iCloud Drive など）の CSV ファイルを読み込む
3. スケジュールが自動で設定される

### カスタム音声の設定

1. 🔊 音声設定ボタンをタップする
2. 個別設定：各アナウンスごとに音声ファイルを選択する
3. 一括設定：フォルダ内の音声ファイルを自動設定する（ファイル名が一致するものに限る）

## 注意事項

- バックグラウンド再生には対応していません
- 再生中はアプリを前面に表示したまま使用してください
- ファイル形式により音声が再生されない場合があります（その場合は `wav 形式` をご使用ください）

## 対応フォーマット

### 音声ファイル

- wav, mp3, m4a, aiff, aif, aac, caf, flac

### CSV フォーマット

```
Date，Time，Announce, Caption
2026/9/19，7:30:00，01_移動開始.mp3, 入室してください
2026/9/19，7:30:30，02_課題閲覧.wav, 課題を読んでください
```

#### 各列の説明

| 列 | 説明 | 必須 |
|---|------|------|
| **Date** | 日付（YYYY/M/D 形式） | 任意 |
| **Time** | 時刻（H:MM:SS 形式） | 必須 |
| **Announce** | 音声ファイル名（拡張子あり） | 任意 |
| **Caption** | スケジュール表示用の説明文 | 任意 |

#### Date 列を空欄にする

**Date 列を空欄にすると、アプリ使用年月日が自動的に使用されます。**

```csv
Date,Time,Announce, Caption
,7:30:00,01_移動開始.mp3, 入室してください
,7:30:30,02_課題閲覧.wav, 課題を読んでください
```

これにより、毎日同じスケジュールを使用できます。

#### Announce 列を空欄にする

**Accounce 列を空欄にすると、音声がスキップされます（無音）。**

```csv
Date,Time,Announce, Caption
,7:30:00,01_移動開始.mp3, 入室してください
,7:30:30,,
,7:31:00,03_課題開始.wav, 課題を始めてください
```

この場合：
- 7:30:00 → 音声が再生される（`01 移動開始`）
- 7:30:30 → 音声がスキップされる（`無音`）
- 7:31:00 → 音声が再生される（`03 課題開始`）

#### Caption 列の使い方

**Caption 列には、スケジュール表示用の説明文を入力します。**

```csv
Date,Time,Announce,Caption
,7:30:00,01_移動開始.mp3，入室してください
,7:30:30,02_課題読む.wav，課題を読んでください
,7:31:00,,休憩時間
```

- スケジュール一覧に表示されます
- 空欄でも動作します（その場合は何も表示されません）
- 音声ファイル名とは無関係です

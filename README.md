# announce

スケジュールに基づいた音声アナウンスアプリです。

## 機能

- 📅 スケジュール管理（CSV 読み込み対応）
- 🔊 音声再生（標準音声 + カスタム音声設定）
- 📱 iPhone/iPad 対応
- 🎵 音声ファイルのカスタマイズ（個別/フォルダ一括設定）

## 使用方法

### デモモード

1. 🗓️ 1/2/3 ボタンでデモスケジュールを選択する
2. ▶️ 再生ボタンでスタートする
3. 設定した時間になると音声が自動再生される

### カスタム CSV の読み込み

1. 📁 CSV 選択ボタンで CSV ファイルを選択する
2. ファイルアプリ（iCloud Drive など）の CSV ファイルを読み込む
3. スケジュールが自動で設定される

### カスタム音声の設定

1. 🔊 音声設定ボタンをタップする
2. 個別設定：各アナウンスごとに音声ファイルを選択する
3. 一括設定：フォルダ内の音声ファイルを自動設定する（ファイル名が一致するものに限る）
   - ファイル名例：
     - `01 移動開始`
     - `02 課題読む`
     - `03 課題開始`
     - `04 課題終了一分前`
     - `05 課題終了・移動開始`
     - `06 課題終了`
     - `17 開始2分前`
     - `18 開始1分前`
     - `19 休憩に入る`
     - `20 放送終了のアナウンス`
     - `26 テストラン開始1分前`

## 音声合成

本アプリでは、一部のアナウンスに [VOICEVOX](https://voicevox.hiroshiba.jp/) の「四国めたん」を使用しています。

- 音声合成：VOICEVOX
- キャラクター：四国めたん
- 利用規約：[VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/)

## 注意事項

- バックグラウンド再生には対応していません
- 再生中はアプリを前面に表示したまま使用してください
- ファイル形式により音声が再生されない場合があります（その場合は `wav 形式` をご使用ください）

## 対応フォーマット

### 音声ファイル

- wav, mp3, m4a, aiff, aif, aac, caf, flac

### CSV フォーマット

```
Date，Time，Announce
2026/9/19，7:30:00，01 移動開始.mp3
2026/9/19，7:30:30，02 課題読む.wav
```

**Date 列を空欄にすると、アプリ使用年月日が自動的に使用されます。**

```
Date,Time,Announce
,7:30:00,01 移動開始.mp3
,7:30:30,02 課題読む.wav
```

これにより、毎日同じスケジュールを使用できます。
